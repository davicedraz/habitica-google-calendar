# Contributing

Thanks for taking the time to contribute.

## Ground rules

- Be respectful and constructive.
- Keep changes focused and easy to review.
- Prefer clear commit messages and PR descriptions.

## Ways to help

- Report bugs or edge cases
- Improve documentation or examples
- Add tests or safer handling
- Propose enhancements

## Reporting bugs

Please include:

- What you expected vs what happened
- Steps to reproduce
- Apps Script logs or error messages
- Screenshot of the trigger or settings (if relevant)

## Proposing changes

1. Fork the repo and create your branch.
2. Make your changes.
3. Open a PR with a clear description and screenshots if UI changes apply.

## Development notes

- This project is a single Apps Script file (`index.gs`).
- Keep the script compatible with Google Apps Script runtime.
- Avoid adding heavy dependencies or external services.
